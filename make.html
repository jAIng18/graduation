Tạo link mời

Chỉ dành cho Tùng. Viết nội dung một lần, thêm khách mời, tạo guests.txt và dán lên GitHub một lần, rồi gửi link.

Trình duyệt này không lưu được dữ liệu (chế độ ẩn danh?). Hãy dùng cửa sổ thường, nếu không danh sách sẽ mất khi đóng trang.

Mỗi mẫu là một kiểu lời mời (bạn bè, gia đình…). {n} = tên khách. Sửa mẫu xong, nhớ vào tab Khách mời để tạo lại guests.txt.

Có thay đổi chưa đưa lên GitHub. Làm lại bước 1–3 bên dưới.

Danh sách

Đưa lên GitHub và gửi

  1. Tạo file (mã hoá lời mời của tất cả khách)
  2. Thay cả file guests.txt trên GitHub
    Bấm nút dưới → bấm vào ô nội dung → Cmd+A (chọn hết) → Cmd+V (dán) → nút xanh Commit changes… (góc trên bên phải) → Commit changes lần nữa.
    Mở guests.txt trên GitHub
  3. Đợi khoảng 1 phút, rồi kiểm tra
  4. Gửi link: copy từng người ở danh sách trên, hoặc copy hết một lần

Sao lưu

Danh sách chỉ lưu trên trình duyệt này. File sao lưu chứa mã bí mật của mọi link, hãy giữ riêng, đừng gửi ai.
